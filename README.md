# C++ Codes — Learning & Competitive Programming Repository

This repository is a curated collection of **C++ programs and problem solutions** gathered from multiple platforms including:

- **Codeforces**  
- **CodeChef**  
- **HackerRank**  
- **Coding Ninjas**

It covers both **fundamental C++ concepts** and **competitive programming problems**, helping learners strengthen their programming and problem-solving skills.

---

## 🎯 Purpose

- Learn and practice **C++ fundamentals** and OOP concepts  
- Solve **algorithmic and data structure problems**  
- Improve **competitive programming skills**  

---

## 📂 Topics & Problem Types Covered

- **Basics:** Loops, Conditionals, Functions, Recursion  
- **Object-Oriented Programming:** Classes, Inheritance, Pointers, Operator Overloading  
- **Data Structures:** Arrays, Strings, Linked Lists, Stacks, Queues, Trees  
- **Algorithms:** Sorting, Searching, Math & Number Theory, Pattern Problems  
- **Competitive Programming:** Problems from Codeforces, CodeChef, HackerRank  
- **File Handling:** Reading/Writing files, Manipulators, Random Access
